# El archivo de las mareas

[Leer el cuento](https://jackthend.github.io/el-archivo-de-las-mareas/)

El mar devolvió a tu hermana en un sobre. Venía sin sello y pesaba como alguien dormido.

Un relato original de fantasía íntima creado con Duvarret: quince escenas, tres finales, cartas, objetos, enigmas y personajes ilustrados en estilo cómic lofi.

Abre el enlace y pulsa **Comenzar**. La música, los efectos y la narración empiezan apagados. Pulsa **Activar sonido** si quieres escucharlos y entra en **Audio-drama sin pantalla** para oír el relato con voz natural y elegir mediante botones táctiles.

Funciona en el navegador de móviles, tabletas y ordenadores, sin cuenta ni instalación. Guarda tu progreso en este navegador y permite reanudarlo. Tras completar la carga inicial, la aplicación web puede abrirse sin conexión.

Este repositorio contiene la publicación del cuento: reproductor web, manifiesto, ilustraciones y grabaciones listas. La edición y generación de voz se hacen en el proyecto de autoría, fuera de este repositorio; los lectores no necesitan modelos de IA.

Texto y sonidos originales creados para esta obra. Las ilustraciones se generaron con IA y la narración con Kokoro local, en una misma interpretación dulce. Reproductor Duvarret: MIT. Modelo Kokoro: Apache-2.0. La procedencia de los recursos se conserva en el proyecto editable.
